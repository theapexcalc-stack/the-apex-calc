# The Apex Calc ⚡

> An ultra-fast, zero-tracking, client-side financial computation and amortization suite built with pure vanilla web technologies.

🔗 **Live Tool:** [https://theapexcalc.netlify.app](https://theapexcalc.netlify.app)

---

## 💡 Overview

Most web-based financial utilities are weighed down by heavy tracking cookies, intrusive video ads, and bloated server-side scripts. **The Apex Calc** was built to deliver instant, institutional-grade calculations locally in the browser with zero external bloat.

## 🛠️ Modules Included

- **Mortgage & Amortization Engine:** Instant calculations for loan principal, monthly repayment structures, and long-term interest schedules.
- **Wage & Salary Converter:** Converts hourly wages into weekly, bi-weekly, monthly, and annual earnings with custom overtime adjustments.
- **Compound Interest Forecaster:** Visual projections for multi-decade wealth growth and periodic contributions.

## 🚀 Key Advantages

- **100% Client-Side:** All computations run natively in the browser via vanilla ES6 JavaScript. No server latency, zero data leaves the machine.
- **Zero Tracking:** No tracking cookies, no third-party analytics bundles, and completely ad-free.
- **Blazing Performance:** Sub-second First Contentful Paint (FCP) and optimal Core Web Vitals hosted on Netlify's global edge network.
